# ☕ Highlands Coffee Data Analytics Project

Dự án tập trung phân tích dữ liệu **Highlands Coffee** để hỗ trợ ra quyết định chiến lược, nâng cao trải nghiệm khách hàng và tối ưu vận hành.  
Các phân tích bao gồm từ **đánh giá chất lượng dữ liệu, xây dựng mô hình, phân tích cạnh tranh**, đến **dự đoán churn và phân khúc khách hàng**.

---

## 📁 Nội dung dự án

1. **Data Quality Assessment and Preprocessing**  
   - Kiểm tra chất lượng dữ liệu: missing values, outliers, dữ liệu không nhất quán.  
   - Tiền xử lý dữ liệu để chuẩn hóa và sẵn sàng cho phân tích.

2. **Data Modeling Diagram**  
   - Thiết kế sơ đồ mô hình dữ liệu (ERD) cho hệ thống Highlands Coffee.  
   - Xác định các thực thể, quan hệ và cấu trúc dữ liệu.

3. **Role-Based Data Access Controls**  
   - Xây dựng cơ chế kiểm soát quyền truy cập dữ liệu theo vai trò người dùng.  
   - Đảm bảo bảo mật và phân quyền trong dashboard và báo cáo.

4. **Competitive Landscape Analysis and Brand Positioning**  
   - Phân tích thị trường và đối thủ cạnh tranh.  
   - Xác định vị trí thương hiệu Highlands Coffee trên thị trường.  

5. **Customer Churn Analysis and Dashboard**  
   - Phân tích khách hàng rời bỏ (churn) và các yếu tố tác động.  
   - Xây dựng dashboard trực quan theo dõi churn rate và hành vi khách hàng.

6. **Customer Segmentation and Churn Prediction**  
   - Phân khúc khách hàng dựa trên hành vi mua hàng, thói quen, độ trung thành.  
   - Dự đoán khả năng churn của từng nhóm khách hàng.  
   - Hỗ trợ ra quyết định chiến lược marketing và giữ chân khách hàng.

---

## 🛠️ Công cụ sử dụng

- **Python**: pandas, numpy, scikit-learn, matplotlib, seaborn  
- **Power BI**: xây dựng dashboard và storytelling  
- **Excel**: truy xuất và xử lý dữ liệu  
- **Machine Learning**: clustering, classification, churn prediction
